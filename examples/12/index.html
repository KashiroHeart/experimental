ツール向けデザインサンプル

#1 JSON Converter の配色・部品（ヘッダー、ペイン、ボタン、セレクト、スイッチ、ステータス行、トースト）を土台に、ツール全般で使う部品と書き方の約束をまとめたページです。右上のボタンでライト / ダークを切り替えられます。

03フォーム要素

見本は実際の要素で、触って確かめられます。:invalid は見本のために常時出していますが、実装では :user-invalid を使い、触る前から赤くしないようにします。

States
要素通常 (:enabled):disabled:invalid
input
type="text" pattern 不一致
type="number" max="8" を超過
type="range" 発生しない値が min〜max に丸められるため
type="checkbox" required・未チェック
type="checkbox":checked 発生しないチェック済みは required を満たす
textarea
textarea required・空
button
重要度：高 対象外入力が不正なら :disabled にする
重要度：低 対象外
select
select required・空の option を選択中
option 対象外検証は select 側で行う

06テキストサンプル（語調）

短く、名詞でラベル・見出し・ボタンは体言で終える。「〜する」「〜を行う」は付けない。
文はです・ますエラー・説明・注意書きのように文になるものは、です・ます調で句点を付ける。
半角の英数字英数字は半角、和文との間に半角スペースを入れる（例: JSON を整形）。
Tone of voice
項目方針例
ラベルinput / textarea何を入れるかを名詞で。単位は括弧で後ろに。
  • 入力 鍵
  • インデント幅 (スペース)
  • 最大サイズ (MB)
ラベルradio / checkbox選んだときに起きることを、目的語＋動詞で。否定形にしない。
  • キーを並べ替える
  • 末尾に改行を入れる
  • radio: 2 スペース タブ
小見出しまとまりの名前を 1 語で。
  • 入力 出力
  • オプション
折り畳みの見出し中身の名前。閉じていても中身が想像できるように。件数があれば右に添える。
  • 詳細設定（3 項目）
  • 変換表の見本
ボタン操作を 2〜4 字の名詞で。主ボタンは 1 画面に 1 つ。
  • 整形 圧縮 検証
  • コピー クリア
  • 入れ替え
トグルボタンON のときの状態を名詞で。状態は表示（有効 / 無効）か見た目で示し、ラベルは変えない。
  • 自動整形
  • 行番号を表示
  • セグメント: 暗号化 / 復号
ツールチップボタンの名前そのもの。キー操作は括弧で添える。説明は 1 文。
  • ファイルを開く
  • 整形 (Ctrl+Enter)
  • 末尾の 0 を保ったまま出力します
エラーどこで・何が・どうすればよいかの順。責めない。
  • 3 行 12 列目: } が足りません。
  • 0〜8 の数値を入れてください。
  • コピーできませんでした。ブラウザの権限を確かめてください。
警告処理は済んだが結果に影響することを、理由とともに。
  • 1 MB を超えるため、色分けを省きました。
  • 重複したキー "id" は後の値を使いました。
情報済んだことを短く。句点なしの体言止めか「〜しました」。
  • コピーしました
  • 有効な JSON です
  • 整形済み · 1.2 KB
機能説明ツールが何をするかを 1〜2 文で。主語は省く。
  • JSON を読みやすく整形したり、1 行に圧縮したりします。
操作方法手順の順に「〜して、〜します」。キーは <kbd> で示す。
  • JSON を貼り付けるか、ファイルをドロップしてください。
  • Ctrl + Enter で整形します。
注意書き事実を淡々と。脅さない。
  • 入力した内容はブラウザの中だけで処理され、送信されません。
  • クリアすると元に戻せません。
